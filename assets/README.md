# Assets

This directory is reserved for visual assets that support the project documentation.

No image files are included in this foundation. When approved concept graphics are ready, the README is prepared to reference these paths without changing its structure:

- `assets/machina-cover.png` — repository cover or hero visual.
- `assets/market-flow.png` — market lifecycle visual.
- `assets/machina-console.png` — future product-concept visual.

Assets should document the concept accurately and must not imply that unimplemented product functionality is live.
